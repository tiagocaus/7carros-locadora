# Sistema de Internacionalização (i18n)

Sistema de tradução para suportar múltiplos idiomas na interface do 7Carros Locadora.

## Idiomas Suportados

| Código | Nome | Bandeira |
|--------|------|----------|
| `pt_BR` | Português (Brasil) | 🇧🇷 |
| `pt_PT` | Português (Portugal) | 🇵🇹 |
| `en_US` | English (US) | 🇺🇸 |
| `es_ES` | Español | 🇪🇸 |
| `it_IT` | Italiano | 🇮🇹 |

## Uso Básico

### Tradução Simples

```php
// Usando helper function t() (recomendado)
echo t('common.buttons.save'); // "Salvar"

// Nas views com template engine
{{ t('common.buttons.cancel') }}
```

### Tradução com Variáveis

Use `:nome` para variáveis substituíveis:

```php
// No arquivo de tradução:
// 'welcome' => 'Bem-vindo(a), :nome!'

echo t('messages.greeting.welcome_user', ['nome' => 'João']);
// Resultado: "Bem-vindo(a), João!"
```

### Tradução em Locale Específico

```php
// Traduzir em inglês, independente do locale atual
echo t('common.buttons.save', [], 'en_US'); // "Save"
```

### Tradução com Pluralização

Use `t_choice()` quando o texto precisa variar conforme a quantidade (singular/plural):

```php
// Sintaxe: t_choice($key, $count, $replace, $locale)
echo t_choice('messages.items', 1);  // "1 item"
echo t_choice('messages.items', 5);  // "5 itens"
echo t_choice('messages.items', 0);  // "0 itens"
```

#### Formato no Arquivo de Tradução

Use o caractere `|` para separar singular e plural:

```php
// app/Lang/pt_BR/messages.php
return [
    'items' => ':count item|:count itens',
    'vehicles' => ':count veículo selecionado|:count veículos selecionados',
    'days_remaining' => 'Falta :count dia|Faltam :count dias',
];
```

```php
// app/Lang/en_US/messages.php
return [
    'items' => ':count item|:count items',
    'vehicles' => ':count vehicle selected|:count vehicles selected',
    'days_remaining' => ':count day remaining|:count days remaining',
];
```

#### Uso nas Views

```php
<!-- Exibir quantidade de resultados -->
<p>{{ t_choice('messages.items', $total) }}</p>

<!-- Com variáveis adicionais -->
<p>{{ t_choice('messages.vehicles', $count, ['extra' => $value]) }}</p>
```

#### Como Funciona

- Se `$count === 1`: usa a primeira parte (antes do `|`)
- Se `$count !== 1`: usa a segunda parte (depois do `|`)
- A variável `:count` é automaticamente substituída pelo valor passado

## Convenção de Chaves

| Chave | Descrição |
|-------|-----------|
| `common.buttons.save` | Arquivo `common.php`, array `buttons`, chave `save` |
| `messages.success.saved` | Arquivo `messages.php`, array `success`, chave `saved` |
| `modules.clientes.title` | Arquivo `modules/clientes.php`, chave `title` |

## Helpers Disponíveis

| Helper | Descrição |
|--------|-----------|
| `t($key, $replace, $locale)` | **Função principal** - Traduz uma chave |
| `t_choice($key, $count, $replace)` | Tradução com pluralização |
| `current_locale()` | Retorna locale atual |
| `set_locale($locale)` | Define locale |
| `locale_info($locale)` | Informações do locale |
| `supported_locales()` | Lista de locales suportados |
| `is_locale_supported($locale)` | Verifica se locale é suportado |
| `has_translation($key)` | Verifica se tradução existe |

## Gerenciamento de Locale

### Obter Locale Atual

```php
$locale = current_locale(); // "pt_BR"
```

### Mudar Locale

```php
set_locale('en_US');
```

### Informações do Locale

```php
$info = locale_info();
// ['name' => 'Português (Brasil)', 'flag' => '🇧🇷', 'code' => 'pt-BR']
```

### Listar Locales Suportados

```php
$locales = supported_locales();
// ['pt_BR' => [...], 'en_US' => [...], ...]
```

## Uso nas Views

### Sintaxe Padrão (Recomendado)

Use a sintaxe de template `{{ }}` com a função `t()`:

```php
<button>{{ t('common.buttons.save') }}</button>
<h1>{{ t('modules.clientes.title') }}</h1>

<!-- Com variáveis -->
<p>{{ t('messages.welcome', ['nome' => $user->nome]) }}</p>
```

### Com Select de Idioma

```php
<select name="locale">
    @foreach (supported_locales() as $code => $info)
        <option value="{{ $code }}" {{ current_locale() === $code ? 'selected' : '' }}>
            {{ $info['flag'] }} {{ $info['name'] }}
        </option>
    @endforeach
</select>
```

## Prioridade de Detecção do Locale

1. `$_SESSION['ui_locale']` - Preferência do usuário
2. `$_SESSION['user_locale']` - Configuração do funcionário
3. `$_SESSION['empresa_ui_locale']` - Configuração da empresa
4. Header `Accept-Language` do navegador
5. Fallback: `pt_BR`

## Adicionando Novas Traduções

### 1. Criar arquivo no locale de referência (pt_BR)

```php
// app/Lang/pt_BR/modules/novo_modulo.php
return [
    'title' => 'Novo Módulo',
    'fields' => [
        'name' => 'Nome',
        'description' => 'Descrição',
    ],
];
```

### 2. Criar equivalente nos outros locales

```php
// app/Lang/en_US/modules/novo_modulo.php
return [
    'title' => 'New Module',
    'fields' => [
        'name' => 'Name',
        'description' => 'Description',
    ],
];
```

### 3. Usar nas views

```php
<h1>{{ t('modules.novo_modulo.title') }}</h1>
```

## Fallback

Se uma tradução não existir no locale atual, o sistema usa automaticamente `pt_BR` como fallback.

Se a tradução não existir em nenhum locale, retorna a própria chave:

```php
echo t('chave.inexistente'); // "chave.inexistente"
```

## Classe Translator

Para uso avançado, acesse diretamente a classe:

```php
use App\I18n\Translator;

$translator = Translator::getInstance();

// Métodos disponíveis
$translator->get($key, $replace, $locale);
$translator->has($key, $locale);
$translator->setLocale($locale);
$translator->getLocale();
$translator->getSupportedLocales();
$translator->isSupported($locale);
$translator->getLocaleInfo($locale);
$translator->clearCache();
$translator->reload();
```

## Tradução de Dados do Banco (Campo JSON)

Para campos que armazenam traduções diretamente no banco de dados usando JSON (ex: `planos_de_contas.descricao_i18n`), use o padrão de campo `_i18n`.

### Estrutura do Campo JSON

```json
{
    "pt_BR": "Caixa",
    "en_US": "Cash",
    "es_ES": "Caja",
    "it_IT": "Cassa",
    "pt_PT": "Caixa"
}
```

### Exemplo: PlanoDeContas::getDescricao()

O Model `PlanoDeContas` implementa um helper estático para obter a descrição traduzida:

```php
use App\Models\PlanoDeContas;

// Buscar plano de contas
$model = new PlanoDeContas();
$plano = $model->buscarPorId(1);

// Obter descrição no idioma atual
$descricao = PlanoDeContas::getDescricao($plano);

// Forçar idioma específico
$descricaoIngles = PlanoDeContas::getDescricao($plano, 'en_US');
```

### Implementação do Helper

```php
public static function getDescricao(array $plano, ?string $locale = null): string
{
    $locale = $locale ?? current_locale();

    if (!empty($plano['descricao_i18n'])) {
        $translations = is_array($plano['descricao_i18n'])
            ? $plano['descricao_i18n']
            : json_decode($plano['descricao_i18n'], true);

        if (isset($translations[$locale])) {
            return $translations[$locale];
        }

        // Fallback para pt_BR
        if (isset($translations['pt_BR'])) {
            return $translations['pt_BR'];
        }
    }

    return '';
}
```

### Quando Usar Campo JSON vs Arquivos de Tradução

| Cenário | Solução |
|---------|---------|
| Textos da interface (labels, botões, mensagens) | Arquivos de tradução (`app/Lang/`) |
| Dados fixos do sistema que precisam tradução | Campo JSON no banco (`_i18n`) |
| Dados criados pelo usuário/tenant | Campo JSON (opcional) ou valor único |

### Vantagens do Campo JSON

- Sem JOINs adicionais
- Flexível para novos idiomas
- Fallback automático para pt_BR
- Compatível com dados existentes
