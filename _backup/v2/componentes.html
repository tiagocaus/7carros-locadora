Lista Modelo (Abstração da Lista de Clientes)

Componente reutilizável baseado na lista de clientes. Pode ser usado para qualquer tipo de lista (veículos, contratos, funcionários, etc.).

Características:

  • Cabeçalho com título e área de ações (busca, botões)
  • Tabela responsiva com colunas ocultas em telas menores
  • Sistema de paginação completo
  • Botões de ação por linha (ver, editar, excluir)
  • Controle de registros por página

Modos de Confirmação:

  • confirmType: 'none' - Sem confirmação de texto. Modal simples com botões Sim/Não (menos seguro, mais rápido)
  • confirmType: 'text' - Usuário digita "EXCLUIR" (case-insensitive: aceita "EXCLUIR", "Excluir", "excluir", etc.)
  • confirmType: 'name' - Usuário digita o nome exato do registro (case-insensitive, mais seguro)

Características de Segurança:

  • Campo de Confirmação Obrigatório - Nos modos 'text' e 'name', o usuário deve digitar o texto correto para habilitar o botão
  • Validação em Tempo Real - O botão só é habilitado quando o texto digitado corresponde ao esperado
  • Comparação Case-Insensitive - Aceita maiúsculas e minúsculas em ambos os modos de confirmação
  • Botão Desabilitado por Padrão - Nos modos com confirmação, o botão inicia desabilitado até a validação

Características Gerais:

  • Usa as mesmas classes do modal genérico (modal-overlay, modal-box)
  • Título fixo: "Confirmar Exclusão"
  • Mensagem dinâmica que pode incluir nome e ID do registro
  • Botão "Cancelar" usa classe btn-secondary
  • Botão "Confirmar Exclusão" usa classe btn-red e só fica habilitado após confirmação

Tipos de Cards Disponíveis:

  • Card KPI (Indicador) - Exibe métricas importantes com ícone e valor destacado. Ideal para dashboards e resumos.
  • Card de Estatísticas com Gráfico - Inclui visualizações de dados (barras, pizza, linhas). Use para análises e relatórios.
  • Card de Lista/Feed - Exibe uma lista de itens com scroll. Perfeito para atividades recentes, notificações ou feeds.
  • Card de Perfil/Informações - Mostra informações de uma entidade (cliente, veículo, etc.) com foto e dados principais.
  • Card de Ação Rápida - Botão visual grande para ações frequentes. Use para criar, adicionar ou acessar funcionalidades.
  • Card de Notificação/Alerta - Exibe mensagens de sucesso, erro, aviso ou informação com cores e ícones apropriados.
  • Card de Progresso - Mostra progresso de uma tarefa ou meta com barra de progresso e percentual.
  • Card de Timeline/Histórico - Exibe eventos em ordem cronológica com linha vertical conectando os itens.
  • Card de Formulário Compacto - Contém campos de formulário em um layout compacto. Ideal para buscas rápidas ou filtros.
  • Card Simples (Básico) - Card genérico para qualquer conteúdo. Use quando nenhum dos outros tipos se adequar.

  • form-input - Input padrão (borda, padding, tamanho) - com foco azul quando ativo

  • form-input-group - Container com borda envolvendo label + input - a borda externa fica azul quando o input interno está em foco
  • form-label-group - Label para uso dentro de form-input-group (sem margin-bottom)
  • form-input-group-field - Input/Select/Textarea para uso dentro de form-input-group (sem borda própria)
  • textarea - Use a classe form-input também para textareas
  • radio - Use classes Tailwind: w-4 h-4 text-sky-600 focus:ring-sky-500 border-slate-300
  • checkbox - Use classes Tailwind: w-4 h-4 text-sky-600 focus:ring-sky-500 border-slate-300 rounded

Nota: Todos os inputs, textareas e selects com as classes form-input ou form-input-focus exibem borda azul e sombra quando estão em foco. Radio buttons e checkboxes usam classes Tailwind específicas para manter consistência visual.

Input Group: A classe form-input-group cria um container com borda que envolve o label e o input. Quando qualquer campo interno está em foco, a borda externa do container muda para azul (#0EA5E9). O input interno não possui borda própria e usa a classe form-input-group-field.

Chosen Select:

  • chosen-select - Classe principal para ativar o chosen-select
  • data-chosen-type="normal" - Tipo normal: mostra todos os registros, busca client-side
  • data-chosen-type="server-side" - Tipo server-side: requer pelo menos 3 letras para buscar
  • data-chosen-search-url - URL da API para busca server-side (obrigatório para server-side)
  • data-chosen-min-chars - Mínimo de caracteres para iniciar busca (padrão: 3)
  • data-chosen-placeholder - Texto placeholder personalizado

<!-- HTML Básico --> <div id="nestableContainer" class="nestable-container"> <ol id="nestableList" class="nestable-list"> <!-- Itens serão inseridos via JavaScript --> </ol> </div> <textarea id="jsonTextareaNestable"></textarea> <!-- Inicializar --> <script src="js/nestable-list.js"></script> <script> // Usar valores padrão (maxDepth = 10) const nestable = new NestableList('nestableContainer', 'jsonTextareaNestable'); // Ou definir profundidade máxima personalizada (0 a N) // Exemplo: permitir apenas 3 níveis (0, 1, 2) // const nestable = new NestableList('nestableContainer', 'jsonTextareaNestable', { maxDepth: 3 }); // Exemplo: sem aninhamento (apenas nível raiz) // const nestable = new NestableList('nestableContainer', 'jsonTextareaNestable', { maxDepth: 0 }); </script>

Como Usar:

  • Cole um JSON no textarea ou clique em "Adicionar Item" para começar
  • Arraste os itens para reorganizar ou criar hierarquias (arraste para dentro de outro item para criar filho)
  • Use os ícones de editar/excluir que aparecem ao passar o mouse sobre cada item
  • O JSON é atualizado automaticamente sempre que você move, adiciona, edita ou exclui itens

Configuração de Profundidade:

  • Por padrão, permite até 10 níveis de aninhamento
  • Você pode definir a profundidade máxima usando o parâmetro maxDepth no construtor
  • Valores válidos: 0 (sem aninhamento, apenas nível raiz) até N (qualquer número positivo)
  • Exemplo: new NestableList('container', 'textarea', { maxDepth: 3 }) permite apenas 3 níveis (0, 1, 2)

Formato JSON:

  • Array de objetos, cada objeto deve ter id e name
  • Para criar filhos, adicione um array children dentro do objeto
  • Exemplo: [{"id":"1","name":"Item 1"},{"id":"2","name":"Item 2","children":[{"id":"3","name":"Item 3"}]}]
